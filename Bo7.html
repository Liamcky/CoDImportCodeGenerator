Call of Duty BO7

Weapon Import Code Generator

How this works:

List equals the ingame codes for each attachment category. It depends on the weapon, what attachment it is!

Some weapon categories have less attachments, keep that in mind.

Just look for the attachments you want to break.

To Import stack a attachment you need to be in broken account state!

Explanation:

1. add 1 attachment (ingame gunsmith)

2. add the attachment you want to stack (ingame gunsmith)

3. add another attachment (ingame gunsmith)

4. Import the attachment you wanted to stack (ingame import)

You can still import multiple attachments even for stacking purpose

Result is the Import code.
